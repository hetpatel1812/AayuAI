Security Information

Last Updated: {{ today_month_year }}

1. In-Memory Processing

Aayu AI uses a strictly in-memory processing pipeline. When you upload a PDF or image, it is temporarily held in RAM for Optical Character Recognition (OCR) and LLM analysis. It is never written to a persistent database or disk drive.

2. Encryption in Transit

All data transmitted between your browser and our servers is secured using industry-standard TLS 1.3 encryption. This ensures that your medical documents cannot be intercepted over public Wi-Fi networks.

3. Authentication

User sessions are securely managed using cryptographically signed cookies. Passwords are salted and hashed using modern algorithms (e.g., bcrypt) and are never stored in plaintext.

4. Infrastructure

Aayu AI is hosted on modern, secure cloud infrastructure that complies with major international security standards. Our environments are routinely updated with the latest security patches.
