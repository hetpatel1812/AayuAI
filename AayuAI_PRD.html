Problem Statement

The Core Problem

Every Indian family gets blood tests done regularly. Nobody understands them. You get a paper full of numbers — Hemoglobin, Creatinine, TSH, SGPT — and either ignore it or pay a doctor ₹500+ just to explain what the numbers mean. India has 1 dermatologist per 1.5 lakh people and a massive primary healthcare gap. Aayu AI fills this gap.

📊 77 Million Diabetics

India is the diabetes capital of the world. Millions get HbA1c, glucose, and insulin tests done but cannot interpret the results or track trends.

💊 Unread Reports

Most blood test reports are filed away unread. The patient understands "normal" or "abnormal" but not what to do about it or why it matters.

🌾 Rural Healthcare Gap

70% of India is rural. Specialist doctors are inaccessible. People travel hours to see a doctor just to get a 5-minute report explanation.

🗣️ Language Barrier

Lab reports are in English. Most patients in Gujarat, UP, Rajasthan, and Bihar cannot read English medical terminology.

Report Input Methods ⭐

🔑 Key Architecture Decision

Three different tools handle three different input types. Gemini 1.5 Flash Vision handles phone camera photos — the most common real-world use case. This is the core innovation of the report analysis pipeline.

📄
Digital PDF Report
pdfplumber

Lab-generated PDF from SRL, Thyrocare, Dr. Lal PathLabs, Metropolis. Text is already digital — pdfplumber extracts it directly with 99% accuracy. No OCR needed.

🖨️
Scanned Image
EasyOCR

Flat scan of a printed report (JPG/PNG). Clear, well-lit, straight image. OpenCV preprocesses (grayscale, denoise, contrast) before EasyOCR extracts text.

📱
Phone Camera Photo ✨
Gemini 1.5 Flash Vision

Real-world photo taken with phone — tilted, shadowed, angled, blurry. Gemini Vision understands the image semantically. No preprocessing needed. Works where EasyOCR fails. FREE tier: 1,500 req/day.

Why Gemini Vision for Phone Photos

Traditional OCR (EasyOCR, Tesseract) reads pixels. Gemini Vision understands images. It handles perspective distortion, shadows, partial blur, and handwritten annotations that break any OCR engine. Since it's already in our free stack as the fallback LLM, using it for vision adds zero extra cost.

Gemini Vision Prompt Strategy

For phone photos, send this exact prompt to Gemini Vision API:

"Extract all blood test parameters from this image. Return JSON array: [{test_name, value, unit, ref_range_low, ref_range_high}]. If a field is unclear, return null."

Gemini returns structured JSON directly — no NLP parsing needed. This skips the entire spaCy pipeline for phone camera inputs.

Flask API Design

POST/uploadUpload report (PDF / image / phone photo)
Body: multipart/form-data — file, member_id, language, report_date
Returns: JSON with report_id, extracted parameters, health_score, redirect URL
GET/result/<report_id>Render full results dashboard
Returns: HTML page with color-coded parameters, explanations, health score, diet tips, specialist suggestion
POST/chatAsk AI chatbot about a report
Body: JSON — report_id, message, history[]. Returns: JSON with assistant_reply from Groq (context-aware to report)
GET/history/<member_id>Get all reports with trend data for member
Returns: JSON with list of reports, parameter_trends[] for Chart.js rendering
POST/translateTranslate report explanations
Body: JSON — report_id, target_lang (hi/gu). Returns: translated explanations, cached in DB for future requests
GET/export/<report_id>Download simplified PDF report
Returns: PDF file generated by ReportLab with color-coded, plain-language summary
GET/compareCompare two reports side by side
Params: report_id_1, report_id_2. Returns: diff JSON with improved/worsened/unchanged parameters
DELETE/report/<report_id>Delete a report and all its data
Soft delete — marks as deleted, retains data for 30 days, then purges

Non-Functional Requirements

⚡

Performance

PDF analysis <5s. Phone photo (Gemini Vision) <10s. Dashboard load <2s. Chatbot reply <3s.

🔒

Security

All reports private per user. bcrypt passwords. No report data logged to any external service. .env API keys never committed.

📱

Responsive

Bootstrap 5 grid system. Works on mobile, tablet, desktop. Phone camera upload flow optimized for mobile UX.

🔁

Reliability

Groq → Gemini fallback. If both APIs down, show cached explanation from DB. Never show blank results.

🌐

Accessibility

Color-coded results also have text labels (not color-only). Hindi/Gujarati improves accessibility for non-English users.

📦

Scalability

SQLite handles up to 100K records. ChromaDB scales locally. HuggingFace Spaces allows upgrade to GPU if needed.

Risks & Mitigations

RiskLevelMitigation
Different lab report formats — SRL, Thyrocare, local labs all format differently. Parser may miss values. High Test on 15+ real reports from Week 2. Use Gemini Vision as fallback for any format — it handles layout variation naturally.
Groq API rate limit hit during demo or heavy usage. Medium Auto-switch to Gemini 1.5 Flash when Groq returns 429. Both keys in .env with try-except fallback in code.
Gemini Vision misreads handwritten or very blurry phone photos. Medium Show confidence flag. Allow user to manually correct extracted values before analysis. EasyOCR as secondary attempt.
Medical accuracy — wrong explanation could mislead user. High Add disclaimer: "This is educational, not medical advice. Consult a doctor for treatment." RAG grounds responses in verified medical KB, not hallucination.
IndicTrans2 translation quality for medical terms in Gujarati. Medium Keep English technical terms (test names, values) untranslated. Only translate explanatory sentences. Use deep-translator as backup.
HuggingFace Spaces cold start — app sleeps after inactivity, slow first load. Low Acceptable for demo. For college presentation, keep app warm by visiting it 1 hour before. Render.com as backup host.
